# Harga Lama (Pricing Sebelum Revisi — Item 7)

Dokumen ini menyimpan versi lama halaman pricing Luxio Project Manager sebelum
direvisi (Item 7). Harga & fitur di bawah ini adalah versi lama.

---

## Paket Lama

### Personal
- Price: Gratis
- Desc: Untuk mulai mengatur target pribadi tanpa biaya.
- Features:
  - 1 user
  - 3 project aktif
  - 25 task aktif
  - Dashboard personal
  - Data tersimpan lokal demo

### Profesional
- Price: 49rb / bulan
- Desc: Untuk pekerja profesional yang butuh ruang kerja tanpa limit.
- Features:
  - 1 user
  - Project & task unlimited
  - Kalender dan reminder
  - Export laporan bulanan
  - Email support

### Grup
- Price: 149rb / bulan
- Desc: Untuk tim kecil yang mulai membagi tugas lintas anggota.
- Features:
  - Hingga 15 anggota
  - 5 divisi
  - Assign task ke anggota
  - Dashboard grup
  - Support prioritas

### Organisasi
- Price: 399rb / bulan
- Desc: Untuk perusahaan, instansi, sekolah, atau lembaga yang butuh kontrol lebih.
- Features:
  - Hingga 100 anggota
  - Divisi unlimited
  - Role admin lengkap
  - Analytics organisasi
  - Priority onboarding

## Catatan Lama
- Semua paket berbayar termasuk backup otomatis, update fitur, dan support via email.
- Paket Personal gratis dengan limit. Tidak perlu kartu kredit.
