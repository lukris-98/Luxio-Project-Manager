Luxio ("kami") adalah aplikasi manajemen project & target yang dapat diakses di https://luxio.web.id. Kebijakan ini menjelaskan data apa yang kami kumpulkan, cara penggunaannya, dan hak kamu sebagai pengguna.

1. Data yang Kami Kumpulkan

  • Data akun: nama, email, username, foto profil (opsional), dan password (disimpan sebagai hash Argon2id, tidak pernah dalam bentuk teks biasa).
  • Data penggunaan aplikasi: project, task, catatan, absensi (foto selfie & lokasi GPS saat absen), gaji/kompensasi, dan pesan chat antar anggota tim.
  • Data integrasi Google (opsional): apabila kamu menghubungkan akun Google, kami menerima nama, email, dan foto profil Google kamu. Untuk fitur Gmail & Blogger, access token OAuth disimpan hanya di browser kamu (sessionStorage) dan tidak dikirim ke server kami.
  • Data teknis: alamat IP, jenis perangkat, dan browser yang tercatat pada log server untuk keamanan dan pencegahan penyalahgunaan.

2. Penggunaan Data Google

Luxio meminta izin (scope) Google berikut hanya bila kamu mengaktifkan fitur terkait:

  • Profil dasar (openid, email, profile): untuk membuat dan mengenali akun kamu saat login dengan Google.
  • Gmail (gmail.readonly, gmail.send, gmail.compose, gmail.modify, gmail.labels): untuk membaca, mengirim, dan mengelola email kamu langsung dari Luxio. Isi email tidak disimpan di server kami.
  • Blogger (blogger): untuk mengelola post dan komentar blog kamu.

Penggunaan dan pengalihan data yang diterima dari Google API mematuhi Kebijakan Data Pengguna API Layanan Google, termasuk persyaratan Limited Use. Data Google tidak kami jual, tidak kami gunakan untuk iklan, dan tidak kami pakai untuk melatih model AI umum.

3. Data yang TIDAK Kami Kumpulkan

  • Password dalam bentuk teks biasa (hanya hash Argon2id yang tidak bisa dibalik).
  • Isi email kamu â€" integrasi Gmail membaca/mengirim email langsung dari browser; isi email tidak disimpan di server kami.
  • Data kartu kredit / pembayaran (fitur berbayar mengikuti proses payment gateway; detail kartu tidak pernah menyentuh server kami).
  • Data pelacakan iklan lintas situs, fingerprint perangkat, atau profil perilaku untuk penjualan data.

5. Cara Kami Menggunakan Data

  • Menyediakan fungsi inti aplikasi (project, task, absensi, gaji, chat).
  • Mengirim email transaksional: verifikasi akun, kode 2FA, notifikasi tugas.
  • Mengirim notifikasi push apabila kamu mengizinkannya di browser/perangkat.
  • Menjaga keamanan layanan, mendeteksi penyalahgunaan, dan menangani laporan masalah.
  • Meningkatkan kualitas layanan melalui analitik agregat & anonim.

6. Cookie & Penyimpanan Lokal

Luxio tidak memakai cookie iklan atau cookie pelacak pihak ketiga. Yang kami gunakan adalah penyimpanan pada browser kamu sendiri:

  • localStorage: menyimpan sesi login, preferensi tema, dan data aplikasi agar tetap bisa dibuka saat offline (PWA).
  • sessionStorage: menyimpan access token Google selama tab masih terbuka.
  • IndexedDB & Cache Storage: dipakai service worker untuk menyimpan aset aplikasi dan antrean sinkronisasi offline.

Menghapus data situs (site data) dari browser akan menghapus seluruh penyimpanan lokal tersebut dan mengeluarkan kamu dari sesi.

7. Penyimpanan & Keamanan

Data disimpan di basis data terkelola (PostgreSQL) dengan koneksi terenkripsi SSL, dan seluruh lalu lintas aplikasi berjalan lewat HTTPS (TLS). Password di-hash dengan Argon2id â€" standar industri untuk penyimpanan password. Token sesi disimpan sebagai hash SHA-256 di server, sehingga kebocoran basis data tidak langsung membocorkan token login. Akses administratif dibatasi, setiap request API melewati autentikasi token, dan endpoint sensitif dilindungi rate limiting.

Token akses Google hanya berada di perangkat kamu (sessionStorage) dan bisa dicabut kapan saja melalui tombol "Keluar" di halaman Gmail/Blogger, atau melalui halaman Aplikasi pihak ketiga di Akun Google.

Transfer data internasional: penyedia infrastruktur kami (database, hosting, email) beroperasi di pusat data di luar Indonesia. Penyedia tersebut menerapkan standar keamanan dan enkripsi setara yang dijelaskan pada kebijakan masing-masing (lihat bagian 8).

Tidak ada sistem yang sepenuhnya bebas risiko. Bila terjadi insiden keamanan yang berdampak pada data pribadi kamu, kami akan memberitahukannya melalui email atau pemberitahuan di dalam aplikasi.

8. Pembagian Data

Kami tidak menjual data pribadi. Data hanya dibagikan kepada penyedia infrastruktur (hosting, database, pengiriman email, push notification) sebatas yang diperlukan untuk menjalankan layanan, kepada Google sesuai izin yang kamu berikan, dan kepada pihak berwenang apabila diwajibkan oleh hukum yang berlaku.

Perlu diketahui: data yang kamu masukkan ke dalam ruang kerja tim (project, task, absensi, gaji, chat) dapat dilihat oleh anggota dan admin tim tersebut sesuai peran masing-masing.

9. Retensi & Penghapusan

Data akun disimpan selama akun masih aktif. Kamu dapat meminta penghapusan akun beserta seluruh datanya kapan saja melalui pemilik aplikasi atau email kontak di bawah; permintaan diproses dalam waktu wajar setelah identitas terverifikasi. Data absensi/foto yang diunggah tetap milik perusahaan/organisasi tempat kamu bergabung sesuai kesepakatan internal.

10. Hak Kamu

  • Mengakses dan memperbaiki data akun kapan saja di halaman Pengaturan.
  • Mencabut akses integrasi Google kapan saja.
  • Menolak atau mematikan notifikasi push dari pengaturan browser/perangkat.
  • Meminta salinan atau penghapusan data pribadi.
