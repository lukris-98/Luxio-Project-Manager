# Privacy Policy — Ringkasan & Poin Wajib Dipatuhi

Sumber resmi: https://huggingface.co/privacy (Effective Date: March 28, 2023)

Privacy Policy mengatur data pribadi apa yang dikumpulkan HF, untuk apa, dan hak Anda. Menggunakan layanan = menyetujui kebijakan ini. Perubahan berlaku 10 hari setelah dipublikasikan.

---

## 1. Data yang Dikumpulkan HF

### A. Yang Anda berikan langsung
- [x] Registrasi: email, password, username, nama lengkap + opsional (avatar, minat, sosmed).
- [x] Pembayaran: data kartu kredit (bila upgrade).
- [x] Konten yang Anda posting (forum, repositori, diskusi).
- [x] Komunikasi Anda dengan HF.

### B. Dari pihak ketiga — untuk mendukung layanan.

### C. Otomatis dari penggunaan
- [x] Sesi: tanggal, lokasi, **IP address**.
- [x] Cookie: login, preferensi.
- [x] Perangkat: tipe, model, versi OS, browser.

### D. Cookies — hanya untuk delivery/update/monitoring/security. Mematikan cookie = tidak bisa memakai layanan.

### E. Do Not Track — HF **menghormati** sinyal DNT: tidak tracking/iklan bila aktif. Warga California bisa minta info disclosure data via privacy@huggingface.co (1x/tahun).

## 2. Penggunaan Data (tujuan legal)

- Deliver layanan (akun, profil, upgrade).
- Operasi & perbaikan layanan (customer service, riset, fixing).
- Komunikasi (welcome email, isu teknis, security announcement).
- Keamanan (deteksi/prevensi fraud).
- Kepatuhan hukum/regulasi.

**Dasar GDPR**: Consent (pakai layanan) + Agreement (perjanjian) + Legitimate interests (keamanan, operasi bisnis, riset).

## 3. Pembagian Data — Prinsip

- [x] HF **TIDAK menjual/sewa/menyewakan** data pribadi.
- Pembagian hanya ke: Affiliates (grup usaha), Third-party providers terdaftar (dibatasi kebutuhan), dengan consent Anda, untuk keamanan, dan kepatuhan hukum.
- Anonymous/aggregated data boleh dibagikan (termasuk untuk iklan tertarget).

## 5. Keamanan Data

- HF memakai standar industri (safeguards administratif/fisik/teknis) tapi **tidak menjamin keamanan absolut**.
- [ ] **Tanggung jawab Anda**: amankan perangkat Anda sendiri — data tertentu bisa tersimpan di device Anda.
- [ ] **Jaga kerahasiaan password** Anda.

## 6. Lokasi Pemrosesan

- Server HF ada di **Amerika Serikat**; data bisa diproses/dipindah ke negara lain tempat affiliate/agent beroperasi.
- Pakai layanan = menyetujui transfer data lintas negara.

## 7. Privasi Anak

- Layanan **tidak ditujukan** untuk anak < 13 tahun; HF tidak sengaja mengumpulkan data mereka.
- Bila terlanjur terkumpul tanpa persetujuan orang tua → HF menghapusnya (laporkan via privacy@huggingface.co).

## 8. Komunikasi & CAN-SPAM
